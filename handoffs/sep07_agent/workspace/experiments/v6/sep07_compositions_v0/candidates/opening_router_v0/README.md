# Opening router v0

Executes the common turn-zero action of public_router and feeltheagi_55. At turn
1, chooses the complete feeltheagi course if the opponent still has only its
original worker; otherwise follows public_router, including its existing shop
and market branches. The choice is fixed before the first differing market
order. No future shop, private opponent state, seed or identity is used.

The single observed feature distinguishes the delayed-hiring public/teammate
opening from the three older counters in our current league. It is a hypothesis
about useful response families, not a universal classifier. Unknown openings
and colliding continuations still need evaluation. Source public_router and
feeltheagi_55 remain unchanged components; their metadata records original code
and replay origins. Selector developed here from the review-7 counterstrategy
cycle and research/opening_features.csv. Common first actions were verified
against 23 opponent packages in both seats. All selection state resets per game.
