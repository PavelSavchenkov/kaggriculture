## Reprioritization

fertilize-before-water dependencies for one-shot crop yield. This is direct
learning from a top replay with lineage, authorized by the user. It need not
become a universal policy: use same-seed ablations, then improve default service
and the approximate model from the result. Also test wheat reserve horizons
separately. Preserve fresh greedy layout and estimated-support modes so the
compiler can realize new proposals, not only replay layouts. Cold independent
compositions and an actual repeating outer search remain required.
