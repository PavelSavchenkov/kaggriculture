# First dated-composition compiler

Observation-driven C++ construction from an empty farm. Program 0 is the dated
individual lifetimes and layout from current leader episode 106277936, seat 0.
All 72 source programs are retained with exact lineage in PROGRAM_SOURCES.json.
The default borrows recorded daily workforce and land support to isolate worker
scheduling error. Template arguments allow a fresh greedy layout and estimated
workforce. It does not replay worker action tapes or access the environment seed.

Worker jobs, assignment, supply pickup, deposit and market logic were developed
here. The structured economic port informed the job/assignment design; its fixed
reserved layout and complete policy were not copied. Productive service follows
engine biology, with survival-safe watering and omission of care that cannot
produce before the horizon. End-dated animals are allowed to escape.

This is an initial compiler, not a promoted strong agent. Exact tests and
requested/realized lifecycle comparisons are required. The complete outer
composition search and financial-estimator integration remain unfinished.
