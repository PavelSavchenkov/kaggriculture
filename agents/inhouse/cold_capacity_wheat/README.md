# cold_capacity_wheat

Diagnostic capacity and production-pressure policy built from scratch. It runs
eight fixed wheat plots with daily labor, waters to a mature one-shot harvest,
and retains up to 92 total wheat before selling only the overflow. That creates
a high-occupancy shed regime and sustained wheat supply without borrowing logic
from an existing agent.

The fixed topology, wheat-only crop mix, large retained inventory, and overflow
sales are the intended phenotype. Admission still depends on fresh-seed match
points, economic floor, failure checks, novelty, and causal exploit evidence.
