# TITAN sale search on the accepted producer

Experimental C++ agents retain empty_sale_slots_m2 and compare partial sales over four/eight turns. The mathematical lot core is unchanged from 216 source-parity cases. Physical/funding integration is local and requires full-game validation. Runtime uses only observations and public configuration. No GPU workload. No submission or promotion.

The cheap search evaluates same-turn/late rival supply stress scenarios. Incoming own stock is projected with a roomy shed; current sales are retained when cash cannot cover projected spending. Promising plans receive exact short replay with fixed producer actions. Held sale positions become PASS; extra trades append. Deferred plans are reconsidered from real observations. Read LINEAGE.json for source and limitations.

Run run_discovery.py, then analyze.py and check_operations.py through conda run -n kaggriculture.
