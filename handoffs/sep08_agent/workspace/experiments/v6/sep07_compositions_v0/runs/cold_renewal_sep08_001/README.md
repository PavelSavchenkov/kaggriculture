search retired crop tiles, replacement of the four added geese by cows/sheep or
no animal, four renewal patterns, tile limits and workforce counts. No new donor
policy is copied. The strong-player production gap motivates more crop cycles.

Run prepare.py once, then run_discovery.py, check_operations.py and analyze.py
through conda run -n kaggriculture. The parent control exactly reproduces the
original dated plan and64 original-compiler full games. Existing solver programs
are omitted here because added crops change their entry states; the original
compiler is held fixed across all composition variants.

own cash but hurts the opponent more; four controlled contrasts are saved.
