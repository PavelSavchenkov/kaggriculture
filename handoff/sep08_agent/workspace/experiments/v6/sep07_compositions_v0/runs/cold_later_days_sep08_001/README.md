# Later-day losses in the cold farm

Compare daily real states with requested lifecycles and the existing productive
biology estimate. The estimate's service assumptions may differ from execution;
it is not an attainable-profit claim. Offline traces expose full diagnostic
states only to this runner; policies still receive the normal observation.
Each trace checks both final cash balances and both full-game action hashes
against saved first-day-compiler discovery results.

The purpose is to identify the first missed birth, feed, care, harvest or funded
expansion before constructing later exact day tasks. Preserve the earlier
placement and first-day results. No incumbent source is changed.
