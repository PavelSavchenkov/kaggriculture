# composition_greedy_v1

Isolated execution ablations over composition_greedy_v0. Mode0 preserves the parent;
bit1 lowers recorded fertilizer/pickup priorities, bit2 permits CARE only after
FEED, bit4 gives a 1.5x score to a continued valid target, and bit8 commits to
that target while it remains available. Episode state belongs to each instance.
Fertilizer-before-water dependencies remain. Indexed and arbitrary dated
composition interfaces are preserved. The manifest exposes program4, source
layout/support/service, one-day input reserve, flexible hiring, mode1.

The first priority, care and movement ablations mostly regress across three
source compositions. Stable targets reduce immediate reversals but increase
total travel. No promotion. The original mode1 manifest passes generic/debug,
thread, PASS and self checks; later source data/target-state additions need
renewed parity. Original source hashes remain in IMPORT.json. The warm library
now contains132courses/32585lives; all original72lifecycles, masks and support
are unchanged, checked by generate_programs_v1.py. PROGRAM_DATA_IMPORT.json
records each source CSV/JSON hash.
