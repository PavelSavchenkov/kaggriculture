# Generic compiler labor diagnosis

Keep each dated composition, placement rule, service rule, purchase ordering and
job assignment fixed. Compare the original pending-job hiring formula with
eight hands, ten hands, and the existing composition estimator's daily worker
count. Source programs 4 and 55 retain recorded layout and service but rebuild
workforce; two independent cold farms use greedy placement and productive service.

The purpose is to measure whether missing worker time explains missed planting
and service. Compare exact production, lifetime fulfillment, funding, paid labor,
movement and idle actions. Extra hiring alone does not establish good routing.
Use source-trace controls to distinguish labor from other compiler failures.

Run prepare.py once, then run_discovery.py. All Python and builds use the
kaggriculture conda environment. LINEAGE.json records the original source hashes,
four hiring modes and discovery-only scenario scope. No promotion is claimed.
