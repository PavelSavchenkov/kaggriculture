# Reproduce one composition-improvement round

From the repository root:

```
conda run -n kaggriculture python experiments/v6/sep07_compositions_v0/scripts/run_ticket_experiment.py 150 king_rc4 experiments/v6/sep07_compositions_v0/runs/justin150_king_tickets_001
```

Use a new run directory for each invocation. The runner builds a content-addressed
C++ binary, records its hash and command, and invokes one whole seed batch.
Python only builds, launches and formats analysis. C++ traces the starting
policy across eight seeds in both seats, checks exact baseline biology and both
cash balances, estimates single-animal changes across matching histories, then
tests eight high-ranked and two low-ranked choices in32 complete games each.
Each choice has an unchanged-animal output-control ablation. The original source
course is evaluated too;16 identity games check the disabled overlay.

`RUN.json` records the binary and compiler invocation. `baseline_cases.csv`
records unsupported traces; `tickets.csv` records dated purchase/pickup/placement
ownership and service. `estimates.csv`, `timing.json` and `calibration.json`
expose matching coverage, costs, output gaps, latency and ranking error.
`proposals/` contains executable agent packages with exact replay lineage;
`compiler_snapshot/` records the compiler code used when the lineage was attached.

This is a bounded composition-search round. It does not automatically promote
the winner or certify funding, stock identity under altered histories, deposit
timing or rival response. Search another opponent or retained source program,
then challenge promising packages against the broader league and unused seeds.
Keep cold compositions, repeated crop rotations, larger rebuilds and the V30
day compiler available; the one-animal neighborhood is not the entire search.

Use `--terminal` to start from the mode3 terminal-improved course. Parent actions
are traced again; old raw-course market/biology traces are not reused. Generated
terminal packages have separate names and PARENT.json metadata. The two Justin
versions are available as opponents. This ordering retains terminal gains while
allowing composition edits; recompile affected worker days afterward because
old optimized action addresses and physical guards may become invalid.
