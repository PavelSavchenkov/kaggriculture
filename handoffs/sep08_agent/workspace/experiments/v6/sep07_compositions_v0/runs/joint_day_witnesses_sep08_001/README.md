# Exact day witnesses for missed compiler work

run.py records four complete C++ source games and checks their hashes and cash
against the earlier joint-route comparison. Each pair starts day14 in the same
full state. The study compares days14..16 with unchanged work or the compiler's
unfinished service and production tasks added, using the same workforce or two
fewer hires. All purchases and sales keep their recorded quantities and slots.

compile.cpp uses virtual field actions only to derive exact requested end tiles
and output. Added inputs are deducted from the actual day contract; the solver
gets neither unlimited stock nor an input route. Each returned schedule must
replay in the full engine with exact inventories, production, deterministic
tiles and cash. Construction tasks are excluded from the extra work. Failures
remain evidence; a solved fixed day does not establish a complete season policy.

Lineage: local day_contract.hpp and dated_day_service_sep08_002 supplied the
contract/solve/replay pattern. Tasks and farm intentions come from
joint_day_routes_sep08_001, with their existing cold-composition and attributed
public-source lives. The scheduler is the persistent root day_solver package.
No new external agent code is copied.
