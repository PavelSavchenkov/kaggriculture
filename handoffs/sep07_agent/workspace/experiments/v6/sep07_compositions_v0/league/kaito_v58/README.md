# Kaito v58

Port of Kaito Fukami's v58 public notebook, from the repository's champion-v58
copy with Pilkwang Kim's loader shim. Ten route controllers use public shops,
capital/assets, persistent public-farm equality, inferred market flow, bounded
sale advances, existing-sale reordering and weed transaction repair. Exact
source and route hashes are in IMPORT.json; source license is Apache-2.0.

All state is per instance; immutable tables are shared. No opponent-private
inventory, seed, future shops or runtime identity is used. Fixed known-stream
capital signatures are retained faithfully but their fresh usefulness must be
measured. All 17,256 source actions match across eight recorded and sixteen
forced full sequences, covering every public branch, mirror latch and market
stress. Generic/debug pair and independent-thread results match in 16 games;
PASS/self checks pass. Discovery: wins 4/256 versus opening_router_v1,
24/256 versus public_router, 248/256 versus Skomuro and all versus Deniz/Arman.
It also loses heavily to fresh Mao and 3정훈 courses. Retain for distinct
behavior; it is not the strongest incumbent. No source-policy optimization.
