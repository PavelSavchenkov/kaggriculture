# Strategy-search learnings

Record positive and negative results with run paths, scope, and next decisions.

## Starting evidence (historical, not new results)

- Exact short-horizon sale arithmetic did not guarantee successful integration: changing stored stock broke future production guards in earlier TITAN experiments. Contracts and full-game validation are mandatory.
- A prior fixed-worker funding repair made an otherwise invalid mixed plan executable, but its full-game margin improved only $33 in one source world. Funding feasibility and plan strength are different objectives.
- Existing economics.hpp approximated same-turn order interleaving and allowed negative cash as a diagnostic. It is useful prior design evidence, not an exact executable financial simulator.
- Both players' receipts must be recomputed when own trading changes market prices. Original final rival cash is not a valid fixed comparator.
- Fixed calendars remove the need for worker routes inside finance, but must still supply storage timing, input use, costs, and capacity semantics.

Test delayed orders on Otter’s supplied farm plans directly (`runs/otter_wait_v0`); keep fixed-replay results separate from live-policy claims.
- Keep both positive and negative results. Each entry should name the tested change, baseline, sample, objective and outcome; state feasibility or behavior changes, evidence path, remaining uncertainty, and the next decision. A failed idea is useful when its failure conditions are clear.
