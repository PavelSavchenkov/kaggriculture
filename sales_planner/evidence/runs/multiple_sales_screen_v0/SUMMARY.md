# Reuse the remaining budget for additional sales

On 394 exposed supplied plans, repeating the existing delivery-bound edit adds $14.04 average margin over one-edit timing (95% episode interval $8.93–21.02). There are 98 gains, no losses and 296 unchanged cases. All checked noncash state and own cash predictions match. Total gain over original orders is $269.95.

The same 1,000 financial-turn budget applies to the complete call. Each accepted edit removes a current sale, and the loop stops if no further edit is accepted or the budget runs out. No holding horizon or threshold is tuned. The run contains 290 calls with two edits, 41 with three and three with four.

This uses supplied funded purchase quantities. Live integration with the existing estimated course calendar and purchase repair is a separate test. Complete replay evaluation costs about 6.55 ms per candidate player-game versus 6.54 ms for one-edit timing, including full-engine comparisons and event output; this is not standalone planner latency. Both controls and all cases remain in this directory.
