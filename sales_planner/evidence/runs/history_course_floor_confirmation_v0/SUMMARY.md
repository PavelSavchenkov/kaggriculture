# Frozen market-inventory guard: fresh confirmation

The unchanged guard was frozen before 128 new seeds. Across 9,216 paired games (six exposed opponents, three fixed Atakan courses, both seats and two shop panels), mean margin gain over purchase repair is $31.39, seed-cluster 95% interval $29.19–33.68. There are 6,980 gains, zero losses and 2,236 unchanged games. Both players' checked physical state, production, terminal stock, discards, worker-days and faults match; no history underestimates or incomplete calendars.

Win/tie utility improves 0.1411 percentage points, interval 0.0434–0.2496. Mean complete own policy time is 5.792 ms/game versus 5.306 ms for control, about 0.486 ms added under this concurrent load. The same farm courses and opponent packages have been exposed before; this is new-seed confirmation, not independent-family transfer.

Keep this as the conservative reusable timing component alongside the original history rule and purchase-repair control. It is not a new main agent or a proved plan selector. The corrected within-day extension is a separate experiment and cannot inherit this promotion evidence. Protocol, source binary hash, all subgroup results and complete paired records remain in this directory.
