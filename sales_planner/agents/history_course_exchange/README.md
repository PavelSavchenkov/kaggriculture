# Revise held sales when another delay is worth more

Experimental wrapper around the fixed courses, purchase repair and multiple-sale delivery timing. The default API course is cows. It uses the remaining portion of the original 1,000 financial-turn budget to consider selling held output now and delaying a different current sale. The two changes are priced together and must preserve work resources and ending private stock and shared market inventory. Neither product can have a competing rival sale before the combined edit finishes.

Motivated by a measured sheep-course example: tomato holds occupy space needed for a later eight-wool wait worth $71. Tests and API checks are pending. This is not a promoted agent or a composition change.
