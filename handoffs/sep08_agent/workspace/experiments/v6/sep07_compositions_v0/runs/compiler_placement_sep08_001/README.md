# Placement and early funding

Compare the inherited distance/quadrant score with filling currently allocated
quadrants before buying more land. Preserve dated crop/animal counts and all
service, purchase-order and hiring rules. The mixed farm keeps eight hands;
goose, dairy and wool use the existing estimator's count for their chosen layout.

Check full games, initial land spending, actual animal birthdays and lifetime
fulfillment. More walking may offset saved land costs; expansion timing may
still be needed later. This is a concrete test of economic placement, not a
universal owned-land-first rule or a claim of competitive construction.
