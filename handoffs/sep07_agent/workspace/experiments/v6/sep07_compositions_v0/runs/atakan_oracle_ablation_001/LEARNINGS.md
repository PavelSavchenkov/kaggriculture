# Findings

- Positive strategy evidence: full-own-plan and rival-flow valuation can rank the reconstructed portfolio almost perfectly when future quantities and shops are supplied. The model has useful structure; its input forecasts need attention.
- Positive profiling practice: use the same exact continuations and factor only estimator inputs. Check both pair ranking and top-choice regret, because better ranking does not always improve the selected branch.
- Negative result: substituting true own quantities alone worsens mean regret by $50.51. Combining true own quantities with true rival quantities and shops improves regret by $210.03 over rival quantities plus shops. Input errors interact; a one-factor null result is not a reason to discard a module.
- Main next test: sample the unknown-shop distribution using only legal state, with shared deterministic scenarios across competing branches. The 35% demand discount and nonlinear plug-in mean can create systematic bias. Oracle gains do not predict the deployable gain from this change.
- Secondary target: forecast dated rival animal output, current public held output, crops, fertilizer and product purchases. Exact rival flows alone improve regret by $389.18; with future shops supplied they improve it by $249.69.
- Bounded price finding: after all oracle quantities and exact demand/costs, six top-branch errors remain in 320 contexts. Daily price approximation is adequate for this portfolio's top choices, but pair-margin MAE remains $1,492 and price errors can matter near ties.
- Null/limited finding: adding exact rival fixed costs changes no top choice here. Correcting town-center fertilizer demand and partial-day consumption changes one choice. This does not prove those terms unimportant for other portfolios or investment dates.
- Validation scope: all games are the previous discovery panel. No new holdout, official runtime, global-strength, causal price-term isolation or deployed-policy claim is made.
