# Cold-farm gap diagnosis

RESULTS.md is the entry point; ANALYSIS.json contains all four actor/opponent
groups and assumptions. run.py reconstructs1024 actual-lifetime biological
models and intended-plan economic forecasts. It exactly reproduces original
p362 intended output and its work deficit. export_opponent.py reruns512 frozen
games in reverse orientation to obtain opponent production, checking both action
hashes, cash and profiles. analyze.py joins the evidence.

Run all commands through conda run -n kaggriculture. Sources remain in this
experiment; INPUTS.json freezes the saved game files. No agent policy changes.
The analysis motivates larger farm renewals, while retaining the demonstrated
need for improved service and funding. Ideal service is conditional biology,
not an executable schedule or certified economic bound.
