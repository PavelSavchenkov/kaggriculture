# Complete useful tile visits

The preceding hiring experiment restored the source worker counts but still
used roughly 778 extra moves per game on each of two replay farms and missed
production. This comparison changes only job assignment scores. One bit favors
work under the worker; another values other possible jobs at the same tile.
The goal is to complete useful work during a visit without committing to a
target that may become obsolete. Earlier persistent-target failures are retained.

Two source farms use original hiring schedules. The cold mixed and goose farms
use their preceding better hiring controls. Mode0 must reproduce these complete
control records exactly. Fixed exposed seeds and two opponents are discovery
only. Compare paid labor, production, moves, missed lifecycles and service rates.
