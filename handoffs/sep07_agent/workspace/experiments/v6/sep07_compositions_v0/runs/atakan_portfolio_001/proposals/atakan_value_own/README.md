# atakan_value_own

Preserved C++ variant of the three-course Atakan Aldemir replay portfolio. The selected mode is explicit in source/agent.hpp; the shared implementation and immutable tables are in ../../source/. All episode/submission IDs, local selector attribution, fixed-source controls, exact action/cash checks and per-opponent results are in [portfolio README](../../README.md), [LINEAGE.json](../../LINEAGE.json), and [REPORT.json](../../REPORT.json). No hidden observation or environment seed enters the policy. This package is a retained specialist or control, not the submitted or broad reference agent.

This package-level README was added during handoff preparation to complete the local-agent directory format. Original C++ sources, manifests and historical validation files are unchanged.
