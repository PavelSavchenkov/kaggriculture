# Runtime model exports

`search_candidate_dev_v2/search_model.hpp` and `context_candidate_dev_v2/context_model.hpp` are the current C++ weights used by the build. Their names reflect the original export stage; accepted and experimental scopes are described in `docs/RESULTS.md`.

Export manifests and compact parity reports are preserved. Their historical CSV references describe the original numerical comparison; the large prediction dumps, superseded models, model-training objects and old executables are in the separate research checkpoint or experiment packaging backup. They are not required to compile or run the current estimator.
